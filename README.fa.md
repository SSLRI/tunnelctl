# تانل‌سی‌تی‌ال (TunnelCTL)

راهنمای فارسی نصب و استفاده.

TunnelCTL یک ابزار خودمیزبان برای راه‌اندازی سرور تونل SSH روی سرور مجازی لینوکسی است.
با یک بار نصب، سه راه مختلف برای اتصال به همان سرویس SSH فراهم می‌شود:

| نوع اتصال | پورت پیش‌فرض | کاربرد |
|---|---|---|
| SSH مستقیم | ۲۲ (به‌همراه یک پورت کمکی) | سریع‌ترین حالت |
| TLS با stunnel | ۴۴۳ | ترافیک شبیه HTTPS معمولی دیده می‌شود |
| WebSocket | ۸۰ | برای کلاینت‌هایی که با پی‌لود کار می‌کنند |
| WebSocket روی TLS | ۸۴۴۳ | ترکیب هر دو |

---

## پیش‌نیازها

- سرور مجازی با اوبونتو ۲۰.۰۴ به بالا، دبیان ۱۱ به بالا، یا خانواده RHEL
- دسترسی روت
- آی‌پی ثابت عمومی
- پورت‌های ۸۰ و ۴۴۳ آزاد باشند (اگر روی سرور وب‌سروری مثل nginx یا apache در حال اجراست، اول آن را متوقف کنید یا موقع نصب پورت دیگری انتخاب کنید)

---

## نصب

با کاربر روت به سرور وصل شوید و این سه دستور را بزنید:

```bash
git clone https://github.com/sslri/tunnelctl.git
cd tunnelctl
sudo bash install.sh
```

اگر `git` روی سرور نصب نیست:

```bash
apt update && apt install -y git
```

نصب‌کننده چند سؤال می‌پرسد. برای هر سؤال، مقدار داخل `[ ]` پیشنهاد پیش‌فرض است؛
اگر همان را می‌خواهید فقط **Enter** بزنید.

سؤال‌ها به ترتیب:

1. آی‌پی یا دامنه سرور — خودش تشخیص می‌دهد، معمولاً درست است
2. پورت SSH — پیش‌فرض ۲۲
3. پورت SSH دوم — پیشنهاد ۲۲۲۲، برای وقتی پورت اصلی مشکل دارد
4. فعال‌سازی TLS روی ۴۴۳ — بله
5. فعال‌سازی WebSocket روی ۸۰ — بله
6. مقادیر پیش‌فرض حساب کاربری: مدت اعتبار (روز)، تعداد اتصال همزمان، سهمیه ترافیک (گیگابایت، صفر یعنی نامحدود)
7. فعال‌سازی fail2ban — بله
8. ساخت اولین کاربر

⚠️ **مهم:** تا وقتی مطمئن نشده‌اید که می‌توانید دوباره با پورت جدید وارد سرور شوید،
سشن SSH فعلی را نبندید. یک ترمینال دوم باز کنید و تست کنید.

## اجرای برنامه

بعد از نصب، هر بار با این دستور وارد پنل می‌شوید:

```bash
sudo tunnelctl
```

منوی اصلی باز می‌شود. **عدد گزینه را تایپ کنید و Enter بزنید.**

```
  1) Accounts             حساب‌های کاربری
  2) Live connections     اتصال‌های فعال
  3) Traffic report       گزارش مصرف
  4) Transports           وضعیت سرویس‌ها
  5) Firewall and hardening   فایروال و امنیت
  6) Backup and restore   پشتیبان‌گیری
  7) Settings             تنظیمات
  8) About                درباره
  0) Exit                 خروج
```

برای برگشت از هر منو، عدد `0` را بزنید.

---

## کار با حساب‌های کاربری

از منوی اصلی `1` را بزنید:

| گزینه | کار |
|---|---|
| 1 | ساخت کاربر جدید |
| 2 | حذف کاربر |
| 3 | قفل کردن یا باز کردن کاربر |
| 4 | تمدید تاریخ انقضا |
| 5 | تغییر رمز |
| 6 | تغییر سقف اتصال و سهمیه ترافیک |
| 7 | نمایش اطلاعات اتصال کاربر |

موقع ساخت کاربر جدید این‌ها پرسیده می‌شود:

- **Username** — فقط حروف کوچک انگلیسی، عدد، خط تیره و زیرخط. بین ۳ تا ۳۰ کاراکتر
- **Password** — اگر Enter بزنید یک رمز تصادفی امن می‌سازد
- **Valid for how many days** — مدت اعتبار به روز، `0` یعنی بدون انقضا
- **Max simultaneous connections** — چند دستگاه همزمان بتوانند وصل شوند
- **Traffic quota in GB** — سهمیه ترافیک، `0` یعنی نامحدود

بعد از ساخت، یک کارت اطلاعات نمایش داده می‌شود که همه‌چیز برای دادن به کاربر داخلش هست.

## دستورات سریع بدون منو

اگر منو نمی‌خواهید، مستقیم از خط فرمان:

```bash
sudo tunnelctl add ali 30 2 50    # کاربر ali، ۳۰ روز، ۲ اتصال، ۵۰ گیگ
sudo tunnelctl show ali           # نمایش اطلاعات اتصال
sudo tunnelctl renew ali 30       # ۳۰ روز تمدید
sudo tunnelctl passwd ali         # رمز جدید
sudo tunnelctl lock ali           # قفل کردن
sudo tunnelctl unlock ali         # باز کردن
sudo tunnelctl del ali            # حذف کامل
sudo tunnelctl list               # لیست همه کاربرها
sudo tunnelctl online             # چه کسانی الان وصل‌اند
sudo tunnelctl traffic            # گزارش مصرف
sudo tunnelctl status             # وضعیت کلی سرور
sudo tunnelctl check              # کدام پورت‌ها باز و در حال گوش دادن‌اند
sudo tunnelctl repair             # بازسازی همه سرویس‌ها و قوانین فایروال
sudo tunnelctl backup             # ساخت فایل پشتیبان
sudo tunnelctl restart            # ری‌استارت همه سرویس‌ها
```

## اتصال از سمت کاربر

### کلاینت‌های موبایل

| فیلد | مقدار |
|---|---|
| Host / Server | آی‌پی یا دامنه سرور |
| Port | ۲۲ برای مستقیم، ۴۴۳ برای TLS، ۸۰ برای WebSocket |
| Username | نام کاربری |
| Password | رمز عبور |
| Mode | Direct یا SSL/TLS یا WebSocket، متناسب با پورت |

پی‌لود برای کلاینت‌هایی که فیلد Payload دارند:

```
GET / HTTP/1.1[crlf]Host: آی‌پی-سرور[crlf]Upgrade: websocket[crlf][crlf]
```

چون گواهی TLS خودامضاست، در تنظیمات کلاینت باید گزینه‌ی پذیرش گواهی نامعتبر
(Allow insecure / Ignore certificate) روشن باشد. اگر دامنه دارید، می‌توانید یک
گواهی واقعی بگیرید و جایگزین `/etc/tunnelctl/certs/stunnel.pem` کنید و بعد
`systemctl restart tunnelctl-tls` بزنید.

### کامپیوتر

```bash
ssh -N -D 1080 -p 22 ali@آی‌پی-سرور
```

بعد مرورگر یا سیستم را روی پروکسی `SOCKS5 127.0.0.1:1080` تنظیم کنید.

## رفع اشکال

| مشکل | راه حل |
|---|---|
| در منو عدد می‌زنم ولی «Unknown option» می‌دهد | نسخه قدیمی است، فایل‌های جدید را جایگزین و دوباره `sudo bash install.sh` بزنید |
| کنار tls یا ws نوشته «not installed» | `sudo tunnelctl repair` |
| پورت ۸۰ یا ۴۴۳ اشغال است | `sudo systemctl stop nginx` یا `apache2`، بعد `sudo tunnelctl repair`. یا از منوی Settings پورت دیگری بگذارید |
| کاربر وصل می‌شود ولی قطع می‌شود | سقف اتصال همزمانش پر شده، از منوی Accounts گزینه ۶ زیادش کنید |
| کاربر اصلاً وصل نمی‌شود | `sudo tunnelctl list` — احتمالاً منقضی شده یا سهمیه‌اش تمام شده |
| سرویسی بالا نمی‌آید | `journalctl -u tunnelctl-ws -u tunnelctl-tls -n 50` |
| پورت دوم (مثلاً ۲۲۲۲) بالا نمیاد | socket activation فعال بوده؛ نسخه ۱.۱.۲ خودکار حلش می‌کند |
| بعد از تغییر پورت از سرور بیرون افتادم | از کنسول وب سرویس‌دهنده وارد شوید و `sudo tunnelctl` را باز کنید |

## حذف کامل

```bash
cd tunnelctl
sudo bash uninstall.sh
```

سرویس‌ها را متوقف و پاک می‌کند، فایل `sshd_config` اصلی را برمی‌گرداند و قبل از
حذف کاربرها و داده‌ها از شما تأیید می‌گیرد.

```
/usr/local/bin/tunnelctl          دستور اصلی
/etc/tunnelctl/tunnelctl.conf     تنظیمات
/etc/tunnelctl/users.db           دیتابیس کاربرها
/etc/tunnelctl/certs/             گواهی TLS
/var/backups/tunnelctl/           فایل‌های پشتیبان
/var/log/tunnelctl.log            لاگ
```
